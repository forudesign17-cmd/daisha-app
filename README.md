# 代車管理くん

車屋の代車・レンタカーを、時間単位のボードで管理するWebアプリ（試作）。

- 画面: ダッシュボード / 日別 / 期間 / 台帳 / 空き検索 / 車両マスタ / ボード表示（大画面）
- 保存先: ブラウザの localStorage（店舗ごとに分かれます。端末間では共有されません）

## ログイン（お試し・デモ用）

`login.html` でログインします。店舗ごとにデータを分けて保存します。

**これはブラウザだけで動く簡易的な仕組みです。** パスワードのハッシュがファイルに入っているため、
強いセキュリティではありません（見学・お試し用です）。本番運用では、サーバー側の認証に置き換えます。

### アカウントを追加する

```bash
python3 tools/add_account.py <店舗ID> <表示名> [パスワード] [--sample]
```

- 店舗ID: 半角英数字とハイフン（小文字）
- パスワードを省略すると、ランダムな16文字を作ります
- `--sample` を付けると、最初にデモ用のサンプルデータ（20台）が入ります。付けない店舗は空の状態から始まります
- パスワードは画面に出さず、`アカウント控え.md`（Gitに入りません）に書き出します
- 追加したら `accounts.js` をコミットして公開してください

### ログイン画面を開かせたくない人へ

`accounts.js` には、パスワードそのものではなくハッシュだけが入っています。
ただし、強いパスワードにしても、公開リポジトリでは誰でも `accounts.js` を見られます。
重要なデータをこの仕組みで守ろうとしないでください。

## 開発

```bash
python3 -m http.server 8765
```

http://localhost:8765/login.html を開きます。
